# RAP

**Restricted Ability Programmers** — небольшая команда, которая делает двухмерную стратегию в реальном времени о современной войне.

## 🎯 О проекте

**War from the Backwoods** — это 2D RTS, в которой игрок берёт на себя роль руководства государства и ведёт военную кампанию. Мы не делаем полную политико-экономическую симуляцию — акцент на военных решениях, управлении фронтом, логистике и оперативном планировании.

Главная цель — глубокая стратегия, которая идёт **даже на слабых компьютерах** благодаря простой 2D-графике и эффективной архитектуре симуляции.

## 🛠️ Технологии

- **Движок:** Godot 4.7 (.NET, GL Compatibility)
- **Язык:** C# / .NET 8
- **Ассеты:** Git LFS
